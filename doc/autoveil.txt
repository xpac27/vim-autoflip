INTRODUCTION                                             *autoveil-introduction*

AutoVeil displays two visual-only C++ type transformations:

  prefer-auto
      Conceal an explicit local-variable type. The conservative level displays
      replacements from clang-tidy modernize-use-auto code actions. An opt-in
      level also accepts simple same-type copies proven by clangd's AST.

  show-deduced-types
      Conceal a simple auto declaration prefix and display the full inferred
      type from a clangd type inlay hint.

AutoVeil never applies a code action or changes buffer text. Editing, undo,
writes, yanks, searches, macros, and Git operate on the original source.

===============================================================================
REQUIREMENTS                                               *autoveil-requirements*

Vim 9.x must have +vim9script, +textprop, +conceal, +channel, and +job.
vim-lsp is required and must attach a running clangd server. clangd needs an
accurate compilation database. For prefer-auto, enable --clang-tidy and:
>
  Diagnostics:
    ClangTidy:
      Add: [modernize-use-auto]
<
For show-deduced-types, enable clangd deduced type hints:
>
  InlayHints:
    DeducedTypes: Yes
<
AutoVeil requests raw hints and does not require vim-lsp's hint renderer.

COMMANDS                                                       *autoveil-commands*

                                                    *:AutoVeilEnable*
:AutoVeilEnable       Enable AutoVeil for the current supported buffer.

                                                    *:AutoVeilDisable*
:AutoVeilDisable      Clear rendering, stop timers, and restore every tracked
                      window's exact conceal options.

                                                    *:AutoVeilToggle*
:AutoVeilToggle       Toggle the current buffer.

                                                    *:AutoVeilMode*
:AutoVeilMode {mode}  Select prefer-auto or show-deduced-types and refresh.

                                            *:AutoVeilPreferAutoLevel*
:AutoVeilPreferAutoLevel {level}
                      Select conservative or same-type-copies and refresh the
                      current prefer-auto buffer.

                                                    *:AutoVeilRefresh*
:AutoVeilRefresh      Force a new visible-range request.

                                                    *:AutoVeilReveal*
:AutoVeilReveal       Temporarily reveal original source spellings.

                                                    *:AutoVeilStatus*
:AutoVeilStatus       Show readiness, mode, generations, cache size, tracked
                      windows, and discarded stale response count.

g:autoveil_enabled_by_default  Boolean. Default: false.

                                                     *g:autoveil_mode*
g:autoveil_mode                String. Default: "prefer-auto".

                                              *g:autoveil_debounce_ms*
g:autoveil_debounce_ms         Number. Default: 300.

                                         *g:autoveil_reveal_on_insert*
g:autoveil_reveal_on_insert    Boolean. Default: true.

                                    *g:autoveil_reveal_under_cursor*
g:autoveil_reveal_under_cursor Boolean. Default: true.

                                        *g:autoveil_max_visible_lines*
g:autoveil_max_visible_lines   Number. Default: 300.

                                           *g:autoveil_type_name_limit*
g:autoveil_type_name_limit     Number. Default: 80. Longer types are skipped.

                                  *g:autoveil_prefer_auto_level*
g:autoveil_prefer_auto_level   String. Default: "conservative".
                      "conservative" uses only modernize-use-auto actions.
                      "same-type-copies" adds clangd AST-proven declarations
                      shaped as a local Type target = source without cv/ref or
                      pointer spelling.

                                    *g:autoveil_max_ast_requests*
g:autoveil_max_ast_requests    Number. Default: 40. Maximum additional AST
                      requests per visible refresh. Zero disables copy
                      candidates without disabling clang-tidy actions.

No mappings are installed.

The public API consists of these commands, configuration variables, and the
AutoVeilAuto and AutoVeilDeducedType highlight groups. b:autoveil_state and
autoload functions are internal. Version 1 emits no User autocommands.

===============================================================================
OPERATION                                                     *autoveil-operation*

AutoVeil requests the visible lines plus a five-line margin. Edits increment a
buffer generation and start a debounce timer. A reply is accepted only when
the buffer still exists, remains enabled in the same mode, and both generation
and changedtick still match.

Accepted candidates become a shared TypeView, then a renderer places virtual
text before the source range and a per-window high-priority Conceal match over
the source. Window-local conceallevel and concealcursor are restored exactly.

InsertEnter reveals source. InsertLeave schedules a fresh request. CursorMoved
reveals when the cursor reaches a rendered source range and keeps it revealed
until the cursor or active window leaves that range. |:AutoVeilReveal| remains
timed. Reveal is buffer-wide because Vim virtual text properties are
buffer-owned; conceal matches and saved options are still window-owned.

At the same-type-copies level, a light lexical scan only discovers possible
one-line copy declarations. It has no semantic authority. Each candidate is
sent through vim-lsp to clangd's textDocument/ast extension. AutoVeil requires
an exact Var declaration/type range and an initializer consisting solely of an
LValueToRValue ImplicitCast over a DeclRef. Every other shape is skipped. Both
this result and normal clang-tidy actions pass through TypeView validation and
rendering without changing the buffer.

===============================================================================
TROUBLESHOOTING                                         *autoveil-troubleshooting*

Use |:AutoVeilStatus| first. A waiting status names the missing dependency,
clangd attachment, or capability. Zero substitutions usually means clangd did
not produce an authoritative candidate or the conservative validator rejected
an ambiguous shape.

Ensure compile_commands.json is accurate. AutoVeil never manufactures flags.
Set g:lsp_log_file and g:lsp_log_verbose to inspect vim-lsp traffic. Keep
g:lsp_inlay_hints_enabled at 0 if duplicated hints appear.

The same-type-copies level requires clangd to advertise astProvider. Select
the conservative level when using an older or incompatible server.

===============================================================================
LIMITATIONS                                                 *autoveil-limitations*

Conservative prefer-auto supports only direct one-edit modernize-use-auto
WorkspaceEdits. same-type-copies additionally supports one-line,
single-declarator Type target = source locals without cv/ref/pointer spelling
when clangd's AST proves no conversion beyond LValueToRValue. Qualifiers,
pointers, references, calls,
constructors, casts, conversions, and ambiguous AST nodes are skipped.

show-deduced-types supports simple initialized local auto declarations.
Command actions, multi-file edits, fields, aliases, function returns,
parameters, structured bindings, macros, direct-list initialization,
incomplete declarations, and ambiguous spellings are skipped. Overlong
inferred labels are skipped rather than truncated.

AutoVeil targets Vim only, not Neovim, Coc, or other LSP clients.
