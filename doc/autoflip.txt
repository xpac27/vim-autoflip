INTRODUCTION                                             *autoflip-introduction*

AutoFlip displays two visual-only C++ type transformations:

  prefer-auto
      Conceal an explicit local-variable type. The conservative level displays
      replacements from clang-tidy modernize-use-auto code actions. Opt-in
      levels also accept progressively broader clangd AST-proven locals.

  show-deduced-types
      Conceal a simple auto declaration prefix and display the full inferred
      type from a clangd type inlay hint.

AutoFlip never applies a code action or changes buffer text. Editing, undo,
writes, yanks, searches, macros, and Git operate on the original source.
The package name is vim-autoflip; commands use AutoFlip and configuration uses
the autoflip namespace. No compatibility aliases are installed.

===============================================================================
REQUIREMENTS                                               *autoflip-requirements*

Vim 9.x must have +vim9script, +textprop, +conceal, +channel, and +job.
vim-lsp is required and must attach a running clangd server. clangd needs an
accurate compilation database. For prefer-auto, enable --clang-tidy and:
>
  Diagnostics:
    ClangTidy:
      Add: [modernize-use-auto]
<
For show-deduced-types, enable clangd deduced type hints:
>
  InlayHints:
    DeducedTypes: Yes
<
AutoFlip requests raw hints and does not require vim-lsp's hint renderer.

COMMANDS                                                       *autoflip-commands*

                                                    *:AutoFlipEnable*
:AutoFlipEnable       Enable AutoFlip for the current supported buffer.

                                                    *:AutoFlipDisable*
:AutoFlipDisable      Clear rendering, stop timers, and restore every tracked
                      window's exact conceal options.

                                                    *:AutoFlipToggle*
:AutoFlipToggle       Toggle the current buffer.

                                                    *:AutoFlipMode*
:AutoFlipMode {mode}  Select prefer-auto or show-deduced-types and refresh.

                                            *:AutoFlipPreferAutoLevel*
:AutoFlipPreferAutoLevel {level}
                      Select conservative, same-type-copies, or
                      ast-proven-locals and refresh the current prefer-auto
                      buffer.

                                                    *:AutoFlipRefresh*
:AutoFlipRefresh      Force a new visible-range request.

                                                    *:AutoFlipReveal*
:AutoFlipReveal       Temporarily reveal original source spellings.

                                                    *:AutoFlipStatus*
:AutoFlipStatus       Show readiness, mode, generations, cache size, tracked
                      windows, and discarded stale response count.

CONFIGURATION                                             *autoflip-configuration*

                                          *g:autoflip_enabled_by_default*
g:autoflip_enabled_by_default  Boolean. Default: false.

                                                     *g:autoflip_mode*
g:autoflip_mode                String. Default: "prefer-auto".

                                              *g:autoflip_debounce_ms*
g:autoflip_debounce_ms         Number. Default: 300.

                                         *g:autoflip_reveal_on_insert*
g:autoflip_reveal_on_insert    Boolean. Default: true.

                                    *g:autoflip_reveal_under_cursor*
g:autoflip_reveal_under_cursor Boolean. Default: true.

                                        *g:autoflip_max_visible_lines*
g:autoflip_max_visible_lines   Number. Default: 300.

                                           *g:autoflip_type_name_limit*
g:autoflip_type_name_limit     Number. Default: 80. Longer types are skipped.

                                  *g:autoflip_prefer_auto_level*
g:autoflip_prefer_auto_level   String. Default: "conservative".
                      "conservative" uses only modernize-use-auto actions.
                      "same-type-copies" adds clangd AST-proven declarations
                      shaped as a local Type target = source without cv/ref or
                      pointer spelling.
                      "ast-proven-locals" retains those results and accepts
                      direct class copies, lvalue Type& target = object[index]
                      bindings, and direct Type* target = source reads when
                      clangd reports their exact AST shapes.
                      Direct call results are also supported and retain a
                      top-level const spelling as const auto.

                                    *g:autoflip_max_ast_requests*
g:autoflip_max_ast_requests    Number. Default: 40. Maximum additional AST
                      requests per visible refresh. Zero disables copy
                      candidates without disabling clang-tidy actions.

No mappings are installed.

The public API consists of these commands, configuration variables, and the
AutoFlipAuto and AutoFlipDeducedType highlight groups. b:autoflip_state and
autoload functions are internal. Version 1 emits no User autocommands.

===============================================================================
OPERATION                                                     *autoflip-operation*

AutoFlip requests the visible lines plus a five-line margin. Edits increment a
buffer generation and start a debounce timer. A reply is accepted only when
the buffer still exists, remains enabled in the same mode, and both generation
and changedtick still match.

Accepted candidates become a shared TypeView, then a renderer places virtual
text before the source range and a per-window high-priority Conceal match over
the source. Window-local conceallevel and concealcursor are restored exactly.

InsertEnter reveals source. InsertLeave schedules a fresh request. CursorMoved
reveals when the cursor reaches a rendered source range and keeps it revealed
until the cursor or active window leaves that range. Every other TypeView stays
rendered. |:AutoFlipReveal| remains timed and reveals all types, as does insert
mode. A cursor-selected type is revealed in every split showing the buffer
because Vim virtual text properties are buffer-owned; unrelated types remain
concealed, and conceal matches and saved options are still window-owned.

At the same-type-copies level, a light lexical scan only discovers possible
one-line copy declarations. It has no semantic authority. Each candidate is
sent through vim-lsp to clangd's textDocument/ast extension. AutoFlip requires
an exact Var declaration/type range and an initializer consisting solely of an
LValueToRValue ImplicitCast over a DeclRef. Every other shape is skipped. Both
this result and normal clang-tidy actions pass through TypeView validation and
rendering without changing the buffer.

The ast-proven-locals level also scans non-cv, single-declarator Type& and
Type* declarations. It accepts only a direct class copy construction, an
lvalue operator[] call for a reference binding, or a direct pointer-variable
read. It also accepts unwrapped Call and CXXMemberCall value results, using
const auto for a top-level const declaration. Exact declaration, type, and
initializer ranges are always required. A direct call may occupy the one line
immediately following its declaration.
PCClangd exposes the lvalue category of overloaded operator[] in its AST
extension arcana field; AutoFlip uses that field only for this proof.

TROUBLESHOOTING                                         *autoflip-troubleshooting*

Use |:AutoFlipStatus| first. A waiting status names the missing dependency,
clangd attachment, or capability. Zero substitutions usually means clangd did
not produce an authoritative candidate or the conservative validator rejected
an ambiguous shape.

Ensure compile_commands.json is accurate. AutoFlip never manufactures flags.
Set g:lsp_log_file and g:lsp_log_verbose to inspect vim-lsp traffic. Keep
g:lsp_inlay_hints_enabled at 0 if duplicated hints appear.

The same-type-copies and ast-proven-locals levels require clangd to advertise
astProvider. Select the conservative level when using an older or incompatible
server.

===============================================================================
LIMITATIONS                                                 *autoflip-limitations*

Conservative prefer-auto supports only direct one-edit modernize-use-auto
WorkspaceEdits. same-type-copies additionally supports one-line,
single-declarator Type target = source locals without cv/ref/pointer spelling
when clangd's AST proves no conversion beyond LValueToRValue. Qualifiers,
pointers, references, calls, constructors, casts, conversions, and ambiguous
AST nodes are skipped at that level. ast-proven-locals additionally accepts
only single & or * declarators with the exact documented AST proof. Rvalue
references, null pointers, conversion-wrapped calls, conversions, macros,
multi-declarators, wider multiline declarations, and ambiguous AST nodes are
skipped.

show-deduced-types supports simple initialized local auto declarations.
Command actions, multi-file edits, fields, aliases, function returns,
parameters, structured bindings, macros, direct-list initialization,
incomplete declarations, and ambiguous spellings are skipped. Overlong
inferred labels are skipped rather than truncated.

Loading the AutoFlip runtime itself after clangd has already published the
current diagnostics cannot recover those past notifications through public
vim-lsp APIs. Normal startup loading caches them before later manual enable.

AutoFlip targets Vim only, not Neovim, Coc, or other LSP clients.
